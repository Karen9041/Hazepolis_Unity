# Hazepolis_Unity
 
Hazepolis 是一款以 2D 橫向捲軸為基礎的動作冒險遊戲。本作由國立臺北教育大學數位科技與設計學系畢業團隊開發，本人(Karen9041)擔任核心程式開發 (Main Programmer)，負責整體遊戲架構設計、機制實作與美術資源整合。

## 負責範疇與技術亮點

- 整體系統架構設計：使用 C# 實作模組化架構，確保遊戲邏輯（如拾取系統、背包系統、對話系統、過場觸發）易於擴充。
